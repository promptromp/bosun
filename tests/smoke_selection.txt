# Which changes the smoke suite's selection (tools/smoke_select.py, `tests/smoke.sh --changed`, the pre-push hook)
# decides without the sections' `covers`. One rule per line: `all <glob>` or `ignore <glob>`. Globs match the
# path from the repository root, whole: `*` within a folder, `**` through any number of them.
#
# For a changed file the order is: `all` (the whole suite), then the sections that cover it (directly or through
# the code that depends on it: see the tool's docstring), then `ignore` (nothing to run), and a file in none of the
# three runs the whole suite. tests/unit/test_smoke_selection.py fails on a tracked file that falls in none, and
# says what to add. When unsure, add it to `all`: the pre-push then does what it did before this file.

# --- all: a change here can reach every section ------------------------------------------------------------------
# The shell library every command sources, and the dispatcher. (What lib/common.sh itself names under lib/, such as
# lib/launch_record.py, is `all` too: the tool reads that from the file.)
all lib/common.sh
all bin/bosun
# The suite itself: its shared setup, its stand-ins, the cache and this selection.
all tests/smoke.sh
all tests/smoke_cache.sh
all tests/smoke_selection.txt
all tools/smoke_select.py
all tests/sandbox/macos/**
# What every window's launch loads: the agents' shell sides (some are named in a variable, which no reader of the
# files could follow), the orchestrator's policy, settings, plugin and task files (every section that starts or
# reads an orchestrator window).
all lib/agents.sh
all lib/launch/**
all lib/harnesses/**
all lib/platforms/**
all orchestrator/**
# Decides which files count as the tree (what is tracked and what is not), and so what selection can see.
all .gitignore

# --- ignore: no section runs or reads these ----------------------------------------------------------------------

# section builds Swift (the `app` section runs app/build.sh against a stand-in swift: it covers build.sh, the

ignore app/**

ignore tests/js/**
